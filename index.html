Settings

1 Go to GitHub Settings → Developer settings → Personal access tokens
2 Click Generate new token (fine-grained)
3 Give it a name (e.g. "Repo Watch")
4 Select for scope: repo (all (public + your private ones) repositories or just public)
5 Click Generate token and copy it
6 Write it down so you don't lose it like me and have to have it in the .env in development
